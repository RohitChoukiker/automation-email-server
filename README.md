> **Inboxonic** is a production-ready full-stack starter for AI-driven email automation: Gmail integration, Gemini-based NLP classification & summarization, smart reply suggestions, and a real-time analytics dashboard.

---

## ⚡ Highlights
- Automatic Gmail sync (OAuth2) and thread detection  
- Gemini LLM (FastAPI microservice) for summarization, intent, urgency, tone, and reply drafts  
- Auto-classification into business labels (Lead, Hiring, Meeting, Billing, Investor, Follow-up, Urgent, Other)  
- Event-driven MongoDB schema with EmailEvent logs and historical metrics  
- Real-time dashboard (React + WebSocket / polling) for inbox analytics  
- Secure: OAuth2, JWT for internal APIs, encrypted refresh tokens, CSP/CORS hardening
